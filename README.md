# FactorGrad-GS project page

Static project page for the anonymous FactorGrad-GS manuscript. The paper
links to this page; its **Code** button points to the separate anonymous
source repository.

Publish this repository as `FACTORGRAD-GS/FACTORGRAD-GS.github.io` with GitHub
Pages set to **Deploy from a branch → main → /(root)**. The resulting project
page URL is `https://factorgrad-gs.github.io/`.

The site uses plain HTML, CSS and JavaScript, with no build step. All asset
paths are relative. The PDF and visual examples are in `assets/`.
